Lingo

读懂，也写得更好。

在网页里翻译、改写和检查文字的轻量 Chrome 扩展，支持简体中文、繁體中文和 English。

选中文字即可翻译、改写或查看词语用法。支持红绿划线建议、个人词典、自定义预设和继续调整；PDF 与复杂编辑器可使用侧边栏。

从 Chrome Web Store 安装 Lingo（Chrome 120+），按引导配置服务并授权网页访问，即可开始使用。

需要手动安装？在 Releases 下载运行包，解压后通过 Chrome 扩展管理页加载。详细步骤见 安装说明。

需要自备 OpenAI 或 Responses API 相容服务的 API Key，用量由所选服务商计费。自动检查默认关闭，开启后会发送当前编辑区全文到所选服务。
