Lingo Privacy Policy

Updated November 9, 2026 · Lingo 1.1.0.
Publisher: Noredge · Support: hongbin.lei98@gmail.com

Processing and destination

After you consent in settings, opening a webpage selection translation, submitting the editable sidebar source, using the PDF/webpage context menu, choosing a writing action or testing the connection sends selected or manually entered text, task instructions, target language, model and optional editing instructions to your configured Base URL plus /responses. The API Key is sent in the authentication header. Opening an empty sidebar or typing into it does not send a request. Refine result sends the currently displayed completed result and your new editing instructions when you submit. It does not send the original text or previous versions as extra context. Browsing versions, opening the form, and typing instructions do not make a request. Up to 20 completed versions per result and unsent instructions remain only in page memory; they are cleared on source changes, closing the panel, or page refresh and are never saved as persistent history. In Words & phrases mode, explicitly opening a selection, switching into the mode with text, or clicking Explain term sends only the current term and explanation instructions, including your interface language, to the configured service. Surrounding page context is not included. Term results and the active mode are held only in page memory; no lookup history is saved. Editing the term or changing interface language alone does not send a request. Testing saves edits when necessary and sends a fixed sample; saving settings alone makes no API request. Inline checking sends the full current text field when you click Check. Your personal dictionary is stored locally. Inline checks include only dictionary entries that appear as whole words in that text, as accepted spellings; the full dictionary is never sent. Adding, searching or removing entries makes no API request and does not edit the source. Grammar and style checks still apply. Automatic checking is off by default. You can enable a global default for all authorized websites or enable individual sites. Website overrides take priority and can be reset to global defaults. No additional site access is granted by these settings. Saving checking settings does not send the current draft: the next focus, return to the page or real edit can check the current supported editor. Enabling a site through the inline card also schedules its existing text. Typing or pasting sends its full text after a pause. Unchanged results are reused within the page to avoid repeated requests. You can turn it off at any time. Lingo does not scan entire webpages, attachments or browsing history. Selected text and automatically checked editor content may include personal communications, such as email drafts. Only select content or enable checks where you intend the configured provider to process it. Results are plain text, never executable code.

The default Base URL is https://api.openai.com/v1. Custom services must implement Responses API; no other protocol or provider-specific adapter is used. External services require HTTPS; HTTP is allowed only on localhost, 127.0.0.1 or ::1 for local APIs. Redirects are rejected. Credentials bind to the full Base URL; editing its address requires that service’s Key and renewed consent. Saving and using a selected profile activates it in the same action without re-entering its Key; failures never switch services automatically. Testing uses the selected saved profile and does not activate it. Requests include store:false, but provider policies still govern retention. The destination is visible in settings and panels.

The chosen provider or proxy receives request content, credentials and necessary network information such as your IP address, and may charge for usage. Its policies and account settings determine logging, retention, processing location and data use. Lingo does not promise zero provider retention. The developer runs no relay, receives none of your API requests, includes no ads or analytics, and does not sell data or use it for unrelated purposes.

Local storage and security

Setup progress and the version of the writing introduction you have seen are stored locally to avoid repeating it. Skipping or completing the introduction preserves existing settings. The local practice exercise uses fixed examples and makes no API calls.

Preferences, named service profiles (address, model, encrypted credentials, storage mode and consent), active profile, translation languages, paused sites, custom rewriting presets, personal dictionary entries, global automatic/style checking defaults and per-site overrides are stored locally without Chrome cloud sync. Chrome manages permissions. Selected or manually pasted source and results stay in panel memory and are removed when it is closed or cleared. A context-menu selection temporarily enters restricted session storage for one-time delivery to the correct window; it is deleted on receipt, expired selections are not processed, and closing the source tab, window or browser clears pending content. It is not written to persistent local storage and no text history is built. Inline text and diagnostics are cached only in page memory for refocusing. Text or checking-configuration changes invalidate them; reloading or closing the page discards them. They are never persisted.

Default remember mode automatically encrypts the Key with AES-256-GCM, using a random non-extractable CryptoKey in extension IndexedDB. Ciphertext and IV are in restricted local storage. No plaintext Key or hard-coded encryption key is persisted. Automatic decryption requires no password after restart. The ability to decrypt resides in the same browser profile; this does not protect against theft of the entire profile or a compromised browser/OS and is not an operating-system keychain or hardware protection.

Optional password mode uses AES-256-GCM and PBKDF2-HMAC-SHA-256 (600,000 iterations), random salt and IV, and a password of at least 12 characters. Neither the password nor the derived key is persisted. Unlock once after browser restart or extension reload. Session-only mode requires entering the Key again after restart/reload. Content scripts cannot read credential stores. Keys are not synced to Chrome cloud, uploaded to GitHub or sent to the developer. Existing password vaults are not automatically downgraded; legacy OpenAI credentials remain bound to the default OpenAI address.

Your controls and support

Revoke site access, pause webpage panels, revoke data consent, lock password mode, delete a service profile or uninstall. Cancellation cannot recall requests already received by a provider. Delete profile removes its address, model, ciphertext and session credentials. Deleting the active profile leaves an empty default connection, never another provider. The shared automatic decryption key is removed only when no other profile needs it; it does not revoke the Key at your provider. Forgotten passwords cannot be recovered. Backups may contain historical data. Text copied or replaced into another website is governed by that website.

Support messages are used only to resolve your request and maintain necessary follow-up records. You may request deletion by email. Never send Keys, passwords or private documents. This policy is bundled with the extension. The public policy website may process normal hosting logs through its hosting provider, GitHub. Material changes will be disclosed and consent requested when needed.

处理与传送的数据

只有你同意设置页的数据处理说明，并打开网页选区翻译、提交侧边栏编辑框的原文、点击 PDF/网页右键翻译、选择写作操作或测试连接时，Lingo 才发起手动 API 请求。请求包含选中或手动输入的文字、操作指令、翻译目标语言、模型及可选的修改要求；API Key 仅在身份验证请求头使用。仅打开空白侧边栏或在侧边栏输入文字不会发送请求。「继续调整」在提交时发送当前显示的完整结果及本次修改要求，不额外附带最初原文或整个版本链。浏览版本、展开表单及输入要求不调用 API。每个结果最多 20 个完整版本与未提交要求仅存于页面内存，修改原文、关闭面板或刷新页面时清除，不持久保存历史。在「单词与短语」模式主动打开选区、有原文时切换至该模式或点击「查看词语」，会将当前词语及包含界面语言的解释指令发送给已配置服务，不附带周围网页上下文。查词结果与当前模式仅保存在页面内存，不保存查词历史；单纯编辑词语或更改界面语言不会发送请求。测试连接在需要时先保存修改，再发送固定示例句；单独保存设置不会调用 API。行内手动检查发送当前输入框全文。个人词典保存在本机，行内检查只附带当前原文中按完整单词匹配的词条，作为认可的拼写；不发送完整词典。添加、搜索或移除词条不调用 API、不修改原文，语法和表达检查仍保留。自动检查默认关闭；可以为所有已授权网页开启全局默认，也可以为单个网站开启。网站单独设置优先，可恢复跟随全局；这些设置不会授予额外网页权限。保存检查设置不发送当前草稿；下次进入支持的编辑区、返回页面或真实编辑后才检查。从行内卡片开启网站检查也会排队检查已有文字。键入或粘贴停顿后，将当前框全文发送至所选服务。相同文本框内容未变时，复用当前页面的结果以避免重复请求。可随时关闭自动检查；不会扫描整页、附件或浏览历史。主动选中或自动检查的编辑区内容可能包括邮件草稿等私人通信；请只选择你愿意交给所选服务商的文字，或在愿意交付内容的编辑区启用自动检查。结果以纯文本显示，不作为代码执行。

数据发往哪里

请求直接发送到你在设置中填写的 Base URL 加 /responses。设置页、浮窗和侧边栏显示服务地址。默认地址为 https://api.openai.com/v1，自定义服务必须支持 Responses API，不使用其他协议或服务商专用适配。外部服务必须使用 HTTPS；仅 localhost、127.0.0.1 和 ::1 允许 HTTP，用于本机 API。请求不跟随重定向。Key 与完整服务根地址绑定，更改配置地址需填写该地址的 Key 并重新确认数据处理说明。选择配置后可通过一次保存并使用来启用，无需重复填写 Key；失败不会自动切换服务。测试只使用所选的已保存配置，不启用它。请求包含 store:false，服务端保留仍受服务商政策约束。

服务商会收到请求文字、凭证和必要网络信息（例如 IP 地址），可能按其账户政策收费。服务商的日志、保存时间、处理地区和数据用途由其政策及账户设置决定；Lingo 不保证服务端零保留。开发者没有中转服务器，不接收你的 API 请求，不加入广告、分析脚本，不出售数据或用于无关用途。选择第三方代理时，该代理就是数据接收方，请先阅读其隐私政策。

本机保存与密钥

首次引导进度及已查看的写作介绍版本保存在本机，用于避免重复提示。跳过或完成介绍会保留原有设置。本地体验使用固定示例，不调用 API。

界面语言、具名服务配置（地址、模型、加密凭据、保存方式及同意状态）、当前启用配置、目标语言列表、暂停名单、自定义改写预设、个人词典、自动检查/表达优化的全局默认及网站例外保存在扩展本机存储。行内原文与诊断仅缓存在当前页面内存中，供重新聚焦时复用；文字或检查配置变更时失效，刷新或关闭页面时丢弃，不写入持久存储。网站/API 访问权限由 Chrome 管理。选中或手动粘贴的原文和结果仅在当前浮窗或侧边栏内存中；关闭或清除窗口会丢弃结果。PDF 右键选区先进入受限的会话存储，供对应窗口的侧边栏一次性接收；接收后删除，过期选区不会处理，关闭原标签页、窗口或浏览器时清除，不写入本机持久存储，不建立文字历史。

默认“记住 Key，免解锁”使用随机 AES-256-GCM 密钥自动加密。密文与 IV 在受限本机存储中，不可导出的 CryptoKey 在扩展 IndexedDB 中。重启后自动解密，无需密码。解密能力也在此浏览器配置中，不能防护完整配置被窃取或浏览器/系统被控制；不等同于系统钥匙串或硬件保护。不持久保存明文 Key，不使用硬编码密钥。

可选“密码加密”使用 AES-256-GCM、随机盐和 IV，以及 PBKDF2-HMAC-SHA-256（600,000 次迭代）。解锁密码至少 12 个字符，不保存密码或其派生密钥，重启浏览器/重载扩展后解锁一次。可选“仅本次会话”在关闭浏览器/重载后需要重新输入 Key。网页内容脚本不能读取凭据存储；Key 不会同步到 Chrome 云端、上传 GitHub 或发送给开发者。已有密码加密凭据不会自动降级；旧版仅 OpenAI 凭据只迁移到默认 OpenAI 地址。

你的控制

你可以撤销网站授权、暂停网页浮窗、取消数据处理同意、锁定密码模式、删除服务配置，或卸载扩展。取消与锁定会停止后续生成，但无法撤回已被服务商接收的请求。删除配置会清除其地址、模型、密文和会话凭据；删除当前配置后回到空白默认连接，不启用其他服务。仅当没有其他配置需要时才删除共享的自动解密密钥，不会在服务商平台撤销 Key。忘记密码只能删除加密副本并重新填写。系统备份或旧版存储可能留有历史副本。复制或替换进其他网站的文字受该网站控制。

支持与变更

支持邮件及附件仅用于处理你的请求与必要的后续记录，可联系上述邮箱请求删除支持记录。请勿发送 Key、密码或私人文档。扩展附有离线政策。公开政策网站的托管方 GitHub 可能依其隐私政策处理基本访问日志。发生实质性数据处理变化时将更新说明，并在需要时重新取得同意。

資料發往哪裡

本機儲存與金鑰

首次引導進度及已查看的寫作介紹版本儲存在本機，用於避免重複提示。略過或完成介紹會保留原有設定。本機練習使用固定示例，不呼叫 API。個人詞典亦僅儲存在本機，不使用 Chrome 雲端同步。

介面語言、具名服務設定（地址、模型、加密憑據、儲存方式及同意狀態）、目前啟用設定、目標語言列表、暫停名單儲存在擴充套件本機儲存。網站/API 訪問許可權由 Chrome 管理。選中或手動貼上的原文和結果僅在當前浮窗或側邊欄記憶體中；關閉或清除視窗會丟棄結果。PDF 右鍵選區先進入受限的會話儲存，供對應視窗的側邊欄一次性接收；接收後刪除，過期選區不會處理，關閉原標籤頁、視窗或瀏覽器時清除，不寫入本機持久儲存，不建立文字歷史。

預設“記住 Key，免解鎖”使用隨機 AES-256-GCM 金鑰自動加密。密文與 IV 在受限本機儲存中，不可匯出的 CryptoKey 在擴充套件 IndexedDB 中。重啟後自動解密，無需密碼。解密能力也在此瀏覽器配置中，不能防護完整配置被竊取或瀏覽器/系統被控制；不等同於系統鑰匙串或硬體保護。不持久儲存明文 Key，不使用硬編碼金鑰。

可選“密碼加密”使用 AES-256-GCM、隨機鹽和 IV，以及 PBKDF2-HMAC-SHA-256（600,000 次迭代）。解鎖密碼至少 12 個字元，不儲存密碼或其派生金鑰，重啟瀏覽器/重新載入擴充功能後解鎖一次。可選“僅本次會話”在關閉瀏覽器/重新載入後需要重新輸入 Key。網頁內容指令碼不能讀取憑據儲存；Key 不會同步到 Chrome 雲端、上傳 GitHub 或傳送給開發者。已有密碼加密憑據不會自動降級；舊版僅 OpenAI 憑據只遷移到預設 OpenAI 地址。

你的控制

你可以撤銷網站授權、暫停網頁浮窗、取消資料處理同意、鎖定密碼模式、刪除服務設定，或解除安裝擴充套件。取消與鎖定會停止後續生成，但無法撤回已被服務商接收的請求。刪除設定會清除其地址、模型、密文和會話憑據；刪除目前設定後回到空白預設連線，不啟用其他服務。僅當沒有其他設定需要時才刪除共享的自動解密金鑰，不會在服務商平臺撤銷 Key。忘記密碼只能刪除加密副本並重新填寫。系統備份或舊版儲存可能留有歷史副本。複製或替換進其他網站的文字受該網站控制。

支援與變更

支援郵件及附件僅用於處理你的請求與必要的後續記錄，可聯絡上述郵箱請求刪除支援記錄。請勿傳送 Key、密碼或私人文件。擴充套件附有離線政策。公開政策網站的託管服務商 GitHub 可能依其隱私政策處理基本託管日誌。發生實質性資料處理變化時將更新說明，並在需要時重新取得同意。
