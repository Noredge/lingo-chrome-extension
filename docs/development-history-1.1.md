# 1.1 开发记录

以下为历史开发阶段记录，不代表商店发布或最终版本验收。dev.19 的状态／闲置优化和 dev.20 的引导已整合到 1.1.0 更新说明。

## 最终界面收敛与发布审查

- 采用用户试用后偏好的原版视觉；移除按钮内 ↵ 图标与重复快捷键小字。翻译不提供继续调整，改写不再显示「校对结果」等重复标题。
- 继续调整仅从最新结果发起；默认显示最新要求与回答，历史可向上滚动，对话模式不显示对比按钮。设置页统一为可按主题跳转的「介绍说明」。
- 拒绝网页脚本模拟点击、目标语言 change 和 requestSubmit 导致的手动 API 调用；真实鼠标与键盘入口继续工作。
- 下方旧阶段记录中的历史版本菜单、从指定版本继续与翻译继续调整均为开发过程，不是最终 1.1 界面。
