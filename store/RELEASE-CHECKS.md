## 审查发现与修复

1. 网页可访问浮窗的开放 shadow root，模拟点击、目标语言变化或表单提交，触发手动 API 请求。已在浮窗入口拒绝这些脚本事件；表单不直接派发任务，保留真实点击、Enter、快捷键和输入法保护。修复前复现 1 次非用户请求；修复后新增 7 项回归全部通过。
2. 检查之前修复的复杂编辑器边界、服务就绪状态、闲置扫描、旧选区失效和富文本格式保留，相关回归通过。
3. 发布材料仍描述旧版对话菜单与翻译继续调整。已统一为当前界面：翻译不提供继续调整；改写无重复结果标题；对话默认显示最新要求与回答、上滚看历史，复制／替换始终使用最新结果，对话中无对比按钮；预设在设置管理，底部统一「介绍说明」。
