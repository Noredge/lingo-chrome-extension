# Lingo 1.1.0 · 数据与权限说明

用于填写既有条目的商店后台，提交时核对实际表单。不能选择“完全不处理用户数据”：即使开发者不接收请求，功能仍处理并向所选 API 服务传送数据。

**单一用途**：在用户阅读和写作时，提供翻译、词语解释、校对、改写及可选行内检查，帮助理解和修改文字。

**数据类别与用途**：
- 网站内容：主动选中／粘贴的文字，或开启自动检查后当前支持编辑区的全文；用于所请求的翻译、解释或写作检查。
- 个人通信：上述内容可能包括邮件草稿或消息；同样发送到用户配置的服务，不扫描附件或整页。
- 身份验证信息：API Key 仅用于所选服务的请求头；本机受限存储保存加密凭据，或仅会话保存。
- 设置：服务地址、模型、语言、同意状态、检查偏好、网站例外、个人词典、自定义预设，以及首次引导进度和已查看介绍版本均保存在本机，不使用 Chrome 云同步。
- 继续调整发送当前最新改写结果与本次要求；查词只发送当前词语及解释指令；行内检查只附带原文中匹配的词典条目，不发送完整词典。

默认关闭自动检查和表达优化。用户自行开启后，进入编辑区、返回页面或输入停顿可能发出请求；保存检查设置本身不会提交草稿。引导练习在本机运行，不调用 API。网页访问授权与自动检查偏好互相独立。

所选服务商接收内容、凭据与必要网络信息。开发者不运营中转、不接收 API 请求，没有广告、分析、出售数据或无关用途；不持久保存文字历史。按功能需要处理数据，不能据此宣称服务商零保留。商店数据披露应覆盖网站内容、个人通信和身份验证信息，提交人按当时表单核对；不要把本机处理等同于“不处理”。

| 权限 | 用途 |
| --- | --- |
| storage | 本机设置、受限凭据和侧边栏一次性交付选区 |
| activeTab / scripting | 用户调用或授权网站的浮窗、检查与受支持选区替换 |
| contextMenus | 用户右键选中文字后翻译 |
| sidePanel | PDF、Google Docs 和受限页面的侧边栏 |
| clipboardWrite | 用户点击复制时写入结果，不读取剪贴板 |
| api.openai.com | 默认 API 地址 |
| optional http/https hosts | 用户授权的网站，以及按需授权的自定义 API 主机 |

没有新增必需权限。外部 API 要求 HTTPS，回环本机服务可用 HTTP；拒绝重定向。凭据绑定完整 Base URL；默认本机加密，可选密码加密或仅会话保存。内容脚本无法读取凭据存储。模型结果仅作纯文本呈现，没有远程可执行代码。

`docs/privacy.html`（公开网站）与 `public/privacy.html`（扩展内副本）必须一致。公开政策部署和实际后台披露须在提交前完成。

参考：[Chrome 用户数据政策说明](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)。
