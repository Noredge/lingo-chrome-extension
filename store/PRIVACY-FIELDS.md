# Lingo 1.0.0 · 数据与权限说明

用于填写商店后台，提交时核对当前表单。不应选择“完全不处理用户数据”。

**单一用途**：用户主动选择或粘贴文字后，提供翻译、校对、改写、复制及受支持编辑器的选区替换。

**处理内容**：选中/粘贴文字、修改指令、目标语言、模型、服务地址、API Key、设置与同意状态。选中文字可能包含网站内容或个人通信；API Key 属于身份验证信息。所选服务商接收 API 请求与必要网络信息；开发者不接收这些请求。没有出售数据、广告、分析、文字历史或与功能无关的用途。

| 权限 | 用途 |
|---|---|
| storage | 本机设置、受限凭据和一次性交付侧边栏的会话选区 |
| activeTab / scripting | 用户调用或授权站点的划词浮窗与受支持选区替换 |
| contextMenus | 用户右键选中文字后翻译 |
| sidePanel | PDF、Google Docs 和受限页面的统一侧边栏 |
| clipboardWrite | 用户点击复制时写入结果，不读取剪贴板 |
| api.openai.com | 默认 API 地址 |
| optional http/https hosts | 用户授权的网站，以及保存自定义 API 配置时按需授权的服务主机 |

外部 API 仅支持 HTTPS，本机回环服务可用 HTTP；不跟随重定向。Key 绑定完整 Base URL，默认 AES-256-GCM 本机加密，可选密码加密或仅会话保存。内容脚本无法读取凭据存储。不存在远程可执行代码，模型结果仅作纯文本呈现。

隐私政策源文件：`docs/privacy.html`（公开网站）与 `public/privacy.html`（扩展内副本），两者一致。服务商保留策略以其政策为准，`store:false` 不代表所有服务商零保留。
