# 数据与权限字段草稿 · 1.0.0-dev.3

尚未提交。正式发布时应按商店后台当时的字段如实填写；不能宣称没有处理用户数据。

单一用途：用户主动选择文字后，提供翻译、校对、改写与复制/支持范围内的选区替换；PDF 使用原生侧边栏。

处理的数据：选中文字（可能含个人通信/敏感信息）、用户修改指令、目标语言、模型、服务地址、API Key、设置/同意状态。Key 属于身份验证信息。服务商接收 API 请求和必要网络信息；开发者不接收 API 请求。没有分析、广告、销售或无关用途。

权限用途：
- storage：设置、受限的密文/会话凭据、一次性交付侧边栏的 PDF 选区；无文字历史、无云同步。
- activeTab / scripting：用户调用或授权站点的选区浮窗、可靠替换；不会注入 Chrome PDF 阅读器。
- contextMenus：明确右键选中文字后翻译。
- sidePanel：在 PDF/可读网页旁展示翻译和复制工具。
- clipboardWrite：仅点击复制时写入结果。
- https://api.openai.com/*：默认 API 主机。其他 Base URL 的主机在用户保存设置时按需授权。
- optional http/https hosts：网页划词授权与可配置 API 主机授权；API 专用授权不会被当成自动划词授权。外部 API 仅 HTTPS，本机回环地址可用 HTTP。

无远程可执行代码。模型输出纯文本。Key 默认自动 AES-256-GCM 本机加密，非系统钥匙串，不保护完整配置失窃；可选密码加密或 session-only。Base URL 与凭据认证绑定，禁止重定向。第三方服务保留时间由其政策决定，不承诺零保留。

隐私政策离线副本：public/privacy.html（简中/繁中/英文）。当前私有仓库的旧 Pages URL 不应直接用于审核；正式发布前需重新部署并验证公开网址。
