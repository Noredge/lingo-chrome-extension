# Lingo 1.0.0 · Reviewer instructions

AI operations require a valid Responses API account, model and quota. No live key is bundled. Arrange any publisher-provided review-only credentials privately in the review channel before submission; do not put them in this repository or the extension package.

1. Install and follow the dismissible setup dialog: interface language, API connection, optional website access. The API and website steps can be deferred. Existing configured users skip onboarding on upgrade.
2. Enter the Base URL, API key and model; review the data destination and consent. “Save and test connection” saves pending edits and sends a fixed sample. Testing does not activate a different profile. Saving settings alone sends no request.
3. Grant a disposable webpage access, refresh it, select text and click 文. Check translation, proofreading, all writing presets, custom instructions, copy, drag and resize. Interface languages are English, Simplified Chinese and Traditional Chinese; translation targets are independent.
4. In a disposable textarea or simple rich-text editor, select only “Can you send me it today?” from “Before. Can you send me it today? After.” Proofread, explicitly replace, and use native Undo. Surrounding text must stay intact; changed selections must not be replaced. Do not send email.
5. In Chrome's native text-based PDF viewer, select text and right-click “Translate with Lingo”. The sidebar source editor opens expanded and shows the selected text. Collapse it and repeat with a new selection; it reopens. Local PDFs may require Chrome's Allow access to file URLs setting. Scanned images need OCR.
6. In Google Docs or another restricted editor, open the sidebar from the extension menu, paste text, translate or rewrite, and copy the result. No direct Docs reading or replacement is included. Typing alone makes no API request.
7. Save multiple service profiles and manually select one. Editing its address requires the corresponding key and renewed consent. Failures never switch providers. Test invalid credentials, network failure and an incompatible response; partial output cannot be applied.
8. Verify default password-free local encryption, optional password unlock/lock and session-only mode. Deleting a profile removes its configuration and credentials. No key appears in the UI after save, source code or store screenshots.
