# Lingo 1.1.2 · Reviewer instructions

This is an update to existing item `imofdjefcigddmfpoifioiejgkfnomip`. AI operations require a valid Responses API account, model and quota. No live key or credits are bundled. No publisher credentials are supplied.

1. Install fresh and follow the six-step guide: interface language, API connection, website access, checking preferences, local practice, writing features. Steps can be deferred. The practice exercise makes no API calls: hover underlines, accept, undo and reset. On upgrade, configured users see a skippable writing introduction when opening settings; it preserves existing connection, dictionary, presets and site preferences. Skipping prevents repeated introduction. Reopen it from settings.
2. Configure a compatible Base URL, API key and model, and review data consent. “Save and test connection” sends a fixed example. Saving alone sends no request. Requests go directly to the chosen endpoint. Automatic checking and style are off by default; site permission does not turn them on.
3. In Writing & checking, verify the check button choices: suggestions only (default), always hidden, and show with text. Empty/whitespace fields always hide it. Saving is disabled when unchanged, enabled after an edit, and disabled again after saving. Changing visibility does not submit text or disable checking. With automatic checking off, right-click a disposable field and choose Check this text field with Lingo; selected text also has a Proofread selected text with Lingo entry that opens proofreading directly in the sidebar.

   Grant a disposable webpage access, refresh, and enter `I has a plan for tomorrow. She go to school every day.` in a normal textarea. Enable automatic checking for that site (or its global default). Focus/type and pause; inspect red underlines without opening the full list. Hover to see the explanation above a pale-green replacement button with an Enter keycap. Click the replacement or press Enter, and verify only that correction is applied and its underline disappears. Related edits remain explicitly listed when applied together. Full-list mode remains open for successive corrections and can locate the text. Style suggestions are optional and model-dependent.
4. Test a disposable simple rich-text field with bold text and links, keeping surrounding text/formatting intact. Verify accept and native Undo. A stale suggestion must not replace newly edited text. Draft.js, CodeMirror, TinyMCE, Google Docs and other complex controlled editors offer copy/sidepanel fallback rather than direct replacement. Do not send email or submit any test form.
5. In Writing & checking settings, add a synthetic proper name to the personal dictionary and repeat a check. Only spelling corrections consisting entirely of accepted words are suppressed; grammar/contextual checks remain. Remove the temporary entry afterwards. Add, edit, reorder and remove a custom preset. These settings operations make no API calls.
6. Select text and use the floating panel: translation, proofreading, presets, result/comparison, copy, explicit replace. Translation has no refinement entry. After rewriting, open Refine result, enter a new request and press Enter; Shift+Enter inserts a newline. The fixed-height conversation initially shows the latest request and answer; scroll upward to read history. Its shared copy/replace actions always use the latest completed result. The conversation has no comparison toggle; collapse it to use the result/comparison view. Collapse/reopen preserves the unsent draft. Manage presets opens the corresponding settings section. The original source stays unchanged until explicit replacement. Editing the source invalidates old results. IME composition Enter must not submit. Words & phrases mode gives usage and examples for a short selection.
7. In a text-based PDF, select text and right-click Translate with Lingo. Verify the editable sidebar source. In Google Docs, paste text into the sidebar, process it, and copy back manually. No direct Docs reading/replacement is provided. Scanned images require OCR.
8. Check English, Simplified Chinese and Traditional Chinese. Test connection errors, refusal/partial responses and cancellation: incomplete results cannot be applied; failures never switch providers. Multiple service profiles remain explicitly selected. Address changes require corresponding credentials and renewed consent.
9. Verify default password-free local encryption, optional password unlock/lock and session-only mode. After restart/reload, password mode needs unlock and session-only mode needs re-entry. Deleting a profile removes its configuration and credentials. No saved key appears in UI/screenshots. Turn automatic checking off to stop future automatic submissions; cancellation cannot recall requests already received by a provider.

Suggestions depend on the configured model and can be inaccurate. The package includes a three-language privacy policy. Store screenshots use synthetic text and clearly labeled fixed responses, not private correspondence.

The settings footer has one Introduction entry for connection, permissions, automatic checking and writing. Existing users can jump directly to any topic; browsing or dismissing it preserves saved preferences and unsaved connection drafts.
