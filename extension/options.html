01

连接 OpenAI

翻译、校对和改写，共用一个连接。

Key 仅在扩展后台使用，不会传给网页脚本。

不勾选时仅保留到本次浏览器会话结束。本机保存不进行云同步，也不等同于系统钥匙串加密。

需支持 Responses API 和流式文本。

02

浮窗翻译语言

只把常用语言放进浮窗，随时添加或移除。

从 31 种语言中挑选常用语言，至少保留一种。保存后，浮窗只显示上方列表。移除默认语言后会改用列表中的第一种；校对和改写默认保留原文语言。

测试会发送一句固定示例，产生少量 API 用量。先保存，再测试。

03

在哪里使用

授权后，划词即可出现小图标。尚未授权时可从扩展菜单临时调用。

所有普通网站

推荐一次授权，在 HTTP / HTTPS 网页划词即用。点击后请在 Chrome 提示中确认；授权不会自动上传网页内容。

也可以只授权下方指定站点，或暂不授权、从工具栏临时调用。

授权后刷新已打开的网页。浏览器内部页、扩展商店和内置 PDF 阅读器不支持。暂停名单优先于授权。

04

开始使用

选中文字 → 点击「文」→ 自动翻译 → 按需修改。

浮窗遮住页面？拖动标题栏移动，拖动四条边或四个角调整大小（最小 320 × 300，较小屏幕自动适配）；点击 ↺ 恢复默认。在当前页面内再次划词会沿用已调整的布局，刷新页面后恢复默认。

快捷入口

右键选中文字，或使用 Alt + Shift + L（Mac 为 Option）。

安全替换

只替换最初选中的部分。原文变动后请重新划选。复杂编辑器保留复制功能。

只在你打开窗口或点击操作时发送选中文字与必要指令至 OpenAI。不会扫描整页，不会读取密码框，不会保存文字历史。所有内容均以纯文本显示。
