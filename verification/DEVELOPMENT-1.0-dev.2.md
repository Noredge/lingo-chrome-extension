# Lingo 1.0.0-dev.2 验证记录

日期：2026-11-02。Chrome 数字版本 0.9.1。开发预览，仓库保持私有，未提交 Chrome Web Store。

## 本版实现

- 网页浮窗与 PDF 侧边栏共用 `src/panel.ts`。翻译、原文折叠、六个改写预设、自定义要求、复制/取消/重试一致；PDF 不提供替换文件内容。
- 按用户选择保留 Chrome 原生 PDF 阅读器与右键翻译，不增加自有阅读器，也不承诺实时监听原生 PDF 选区。
- 唯一协议为 Responses API。支持标准 SSE（不依赖 DONE）和完整 JSON，拒绝 Chat-only、截断、拒绝与错误结果。
- 多套具名配置独立保存地址、模型、Key、存储方式与同意；只有明确激活才切换，测试不会激活，失败不回退。
- 旧版密文、密码模式和默认免解锁模式自动迁移；不打印、读取或复制用户真实 Key。
- 界面语言在右上角即时切换；说明精简，密钥高级选项与指定站点管理折叠。

## 原生 PDF UI 验证

使用有界面的 Chrome for Testing、合成 PDF 和模拟 Responses 输出，实际鼠标选字与右键菜单：

- HTTP PDF：右键 Translate with Lingo 打开原生侧边栏并显示翻译。
- 原生侧边栏显示与浮窗相同的全部六个预设；实际点击 Professional 和自定义改写，翻译保留，写作结果独立显示。
- 清除按钮丢弃原文/结果；内置关闭按钮确实关闭 Chrome 侧边栏。
- 本机 file:// PDF：同一右键流程成功显示结果，不需要读取整个文件。
- 共 4 次被拦截的 API 请求，无真实服务调用。截图 `pdf-native-shared-panel.png` 是合成内容。

## 验证边界

本轮未调用真实 OpenAI / 自定义提供商，未重新在登录用户的 Gmail 发送或修改真实邮件。既有真实服务验证属于旧版历史记录，不计入上述本版结果。自定义服务需要实现 Responses API；“OpenAI 相容”标签不代表一定支持。正式发布前仍应由用户用自己的配置确认真实模型、额度、输出质量与延迟。
