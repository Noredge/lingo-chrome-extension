# Lingo 1.0.0-dev.3 验证记录

2026-11-02 · Chrome 数字版本 0.9.2。开发预览，仓库保持私有，未提交商店。

本版将 PDF 侧边栏原文改为可编辑文本框：支持手动粘贴、点击翻译或 ⌘/Ctrl+Enter。输入不发送 API，立即停止旧请求并清掉旧结果，写作预设使用编辑后的原文。空白及超过 16,000 字符的内容不能提交。原生 PDF 右键入口保留，未新增 PDF 阅读器或实时选区监控。

设置页仅在字段确有改动或选择另一套服务时显示保存条，成功保存或撤回改动后收起。选择另一套服务后一次“保存并使用此配置”完成保存与切换；校验失败时原服务不变。测试按钮独立保留，未保存的编辑不能测试。切换编辑对象时可以取消放弃草稿。

删除 Key 的独立界面入口已移除。删除配置一并移除地址、模型及该配置凭据；删除当前配置时建立无 Key、无同意状态的空白默认连接，不擅自启用其他保存的服务。其他配置的自动解密能力保持。
