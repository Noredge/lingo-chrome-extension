# Google Docs 专项适配：可行性验证

2026-11-02 · 基于 Lingo 1.0.0-dev.7 / 26865e5。结论：**有条件可行，尚不适合默认启用。**

本实验在用户的真实 Chrome 中运行，专用临时文档只含人工测试句子。Chrome 扩展内的内容脚本完成选区读取与替换；Google Docs 连接器仅用于创建测试数据和读回持久化结果，没有代替扩展执行待验证的替换。没有调用模型 API、读取用户 Key、增加权限或修改用户已有文档。

## 实测结果

| 检查 | 结果 |
|---|---|
| 普通 `window.getSelection()` | 顶层为空；Docs 输入 iframe 通常只提供 NBSP 占位字符 |
| 页面 Canvas 的 SVG 文本注释 | 当前测试环境没有可用的 `svg [aria-label]` 文本 |
| 显式按钮执行输入 iframe 的 `execCommand('copy')` | 成功；约 80ms 后从 iframe DOM Selection 读到实际选中文字 |
| `ClipboardEvent.clipboardData` | 本次事件没有提供文字；实际文字来自 Docs 的临时输入 DOM |
| `execCommand('insertText')` | 返回 false，没有完成替换 |
| 向 Docs 输入节点派发含 plain text 的合成 paste 事件 | 成功；连接器读回确认写入真实文档，不只是临时 DOM |
| 单段替换 + Chrome 中 Cmd+Z | 成功；原文恢复 |
| 同文档出现两个相同句子 | 先捕获第一处，再移动到第三段；旧快照被拦截。重新捕获后仅第三段被替换，第一段保持原样 |
| 跨两段读取、替换及撤销 | 成功，选区内含中文和 emoji；两段合并成指定结果，选区外两段保持原样，撤销恢复全部原文 |
| 读取时保留剪贴板 | 未通过。普通 Copy 覆盖剪贴板；分别在冒泡/捕获阶段阻止 copy 默认行为后，哨兵值仍被选中文字覆盖 |

`persisted-results.json` 保存连接器读回的关键结果及修订 ID。测试替换固定输出为 `Can you send it to me today?`，并非 AI 生成结果。

## 原型结构与范围

`probe.js` 只在明确列出的测试文档 ID 上生效，挂载独立诊断控件；不包含在 Vite 正常构建中。输入节点定位使用实际观察到的 `.docs-texteventtarget-iframe`。诊断面板按钮阻止 mousedown 转移编辑焦点。

保护原型在捕获时记录用户交互序号与原文；键盘、鼠标、输入、窗口失焦/可见性变化使旧快照失效。替换前重新读取并核对原文和交互序号，快照使用一次即销毁。它证明基本防误替换可以实现，**不是完整的协作编辑安全方案**。

仍需解决：

- 读取依赖复制操作，当前会覆盖剪贴板；不应放进每次 mouseup 自动执行的流程。可以先做明确的“复制并读取”操作，或验证用户主动复制后的导入方案。
- 多段选区通过 DOM `Selection.toString()` 读取时出现双换行；正式实现需要依据实际段落结构处理，不能盲目删除所有空行。
- 80ms 等待只是实验参数，正式实现应等待可验证的新选区数据并设置超时，防止把上一次缓存当作当前原文。
- 没有验证粗体、链接、列表、表格、建议模式、只读文档、多文档标签、输入法及多人协作。plain-text paste 不应被描述为保留任意格式。
- 用户交互序号不能证明远端协作者没有修改文档。替换需要更多位置/版本证据；证据不足应退回复制。
- Docs 输入节点和复制/粘贴处理属于页面实现细节，Google 更新后需要回归。`dispatchEvent()` 的返回值也不能证明持久化成功，本实验单独读回文档确认。

## 重现方式

1. 保留已安装版本备份。在临时、人工测试文档上使用此探针，并将 `testPath` 改为该文档的路径。
2. 正常构建 Lingo，将探针追加到**测试安装目录**的 `content.js`，重新加载扩展，再刷新测试文档；不要改变权限。
3. 在 Docs 中选中文字，点击“记录选区”，检查诊断中原文；点击“替换已记录选区”后核对文档，再按 Cmd+Z。
4. 捕获后移动到另一处同样文字，点击替换，应提示 `Selection changed; capture again. No write.`。
5. 使用“写入测试剪贴板”按钮设置哨兵，记录选区，然后在“剪贴板检查”中手动粘贴；当前结果证明剪贴板仍被覆盖。此测试会主动改写剪贴板。
6. 完成后用正常构建恢复测试安装目录并重新加载，刷新测试文档移除探针。

本次已恢复安装目录，确认其 22 个运行文件与 dev.7 正常构建逐文件一致；真实 Chrome 中实验控件已消失。测试文档已撤销恢复原文，保留用于复查。没有发布新扩展版本或改变默认行为。
